# Specs from Sam's grill

Each file is a spec written at the end of a `/grill` in #app-requests and DM'd to Jamie. Nothing here is built
automatically. Every weekday at 08:47 (SA time) a scheduled Claude check in Jamie's FOMO Apps project reads any
new spec here, reviews it (read only) against the code, live data and other work in flight, and reports
go / change this / don't build. Jamie decides.
