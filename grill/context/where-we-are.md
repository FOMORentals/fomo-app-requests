## 3. Shared conventions

- **Team note → #whats-new.** Every PR body has `## Team note` (headline / what changed / what you do / picture under `whats-new/` / try it). The "Team note picture" GitHub check (all 8 app repos) goes red without a picture, but **doesn't block the merge**, so add the picture before merging. Jamie has been very frustrated by notes going out without pictures: verify end to end.
- **Which repos announce:** `fomo-whats-new/lib/apps.ts` lists the 8 app repos. A new app (e.g. the consignor portal) needs adding there, plus the PR template and picture check copied in, plus the GitHub token's repo list updated.
- **PR attribution:** every PR body starts with the attribution lines; FOMORentals is assignee and reviewer.
- **Engineering rules:** `~/Code/FOMO-ENGINEERING-RULES.md` (copy in this project) and the longer `FOMO-ENGINEERING-GUIDELINES.md` (estate map, incident log, read-only gcloud commands).
- **Slack apps:** "FOMO Overtime" (#rentals_overtime, C06J9KBAAGG), "What's new" (#whats-new, C0CFKGHRCNT). The dashboard and Cloud Function post alerts to #systems-alerts with plain-English "what to do" lines.
- **Admins and approvers:** Overtime admins Sam + Jamie. What's new: Jamie approves notes. Invoice chasing editors: Jamie + Sam. Kit onboarding Push: Jamie, Sam, Will. Client portal staff admin: anyone with a fomorentals.co.uk Google login.
- **Logins:** staff sign in with Google (fomorentals.co.uk). Overtime and What's new pages use signed links from Slack, no login.
- **Alerts:** dev emails land in jamie@fomorentals.co.uk under Gmail labels Dev/Alerts and Dev/Noise; GitHub and Vercel deploy emails are muted. A daily digest of real problems was planned but not built.
- **Costs:** Google Cloud is mostly Firestore reads from the dashboard; cut from ~£215 to ~£30–35 a month by 11 Nov. Don't add whole-collection reads.
- **Claude API key:** apps use the jamie@fomorentals.co.uk Console org (keys: vercel-bookings-board, google-cloud, local-dev).
- **Worktrees:** create them inside the repo's `.claude/worktrees`, not as sibling folders in `~/Code` (Jamie found the folder confusing; tidied 28 Oct, old copies in `~/Code/_archive`).
